**Architecture and design pattern study**<br>
* **Advanced systems (KitchenChaos - CodeMonkey)** a deep dive into scalable architecture, implementing the Command Pattern, separated UI logic, and static instance management for a complex simulation loop. Seasoned by event-driven logic and scriptable objects.<br>
* **Turn-based strategy (TPS - CodeMonkey)** built a grid-based tactical combat system focusing on A* pathfinding, unit state management, and Action Point systems.<br>
* **RPG Systems (RPGMate - GamedevTV / JRPG - StephenScottDay)** engineered core RPG components including inventory management, player movement, player combat, branching dialogue systems, and persistent world states across scene transitions.<br>

**Physics and mechanic reproduction**<br>
* **Physics and vector logic (AngryAntivaxxers)** a code-first implementation of projectile trajectory and direction-based damage. Scripted the physics interactions and collision logic manually to understand the underlying vector mathematics of artillery mechanics.<br>
* **Core loop analysis (Galaxy / Snake)** recreated fundamental arcade algorithms to understand input buffers, grid movement constraints, and frame-dependent logic in both Unity and Unreal Engine.<br>
