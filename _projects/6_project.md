**Parking Master: Low-Poly (mobile title - previously on Google Play Store)**<br>
* **Mobile architecture** designed and shipped a casual arcade game, managing the full lifecycle from gameplay implementation to Google Play Store deployment.<br>
* **Performance optimization** utilized Unity Profiler and ADB logcat to diagnose memory leaks and optimize draw calls for low-end Android devices.<br>
* **Platform integration** implemented Google Play Games Services (Leaderboards/Achievements) and handled mobile-specific constraints (touch input layers, resolution scaling).<br>
* **Core systems** developed modular level generation, vehicle physics, and a persistent economy system (currency/unlockables).<br>

**5yearsApp2D (full-stack Unity application)**<br>
* **Client-server architecture** engineered a non-game productivity application using Unity as a cross-platform reactive client.<br>
* **Backend integration** built a robust data layer connecting the C# Unity client to a .NET host API and NoSQL Firebase database for real-time data persistence.<br>
* **UX/UI design** designed a responsive mobile interface focused on text input handling and long-term data visualization (5-year retrospective timeline).<br>
